# 个人博客视觉与设计规范

## 1. 设计目标

这套博客的视觉设计要同时满足 4 个目标：

- 让人一眼感受到这是“你的站”，而不是通用模板
- 保证文章阅读体验足够舒服
- 在浅色和深色模式下都保持完整气质
- 控制界面复杂度，保持克制和长期可维护

整体方向不是“花哨作品集”，也不是“纯文档站”，而是介于两者之间的个人内容网站。

## 2. 设计关键词

建议整体视觉关键词如下：

- 安静
- 克制
- 有质感
- 有人格化表达
- 重视排版
- 现代但不过度科技感

## 3. 整体视觉方向

### 推荐风格

建议采用：
- 大留白
- 强排版
- 少量强调色
- 柔和层次
- 清晰边界但不过度卡片化

不建议：
- 满屏功能卡片
- 过多渐变
- 过多荧光色
- 过重的阴影
- 很强的 SaaS 仪表盘风格

### 页面气质

首页：
- 更有氛围感
- 更强调“个人感”和第一印象

文章页：
- 更安静
- 更偏阅读器体验

列表页：
- 更整洁
- 信息密度适中

## 4. 主题系统

### 设计原则

- 使用语义化 token，不直接在组件里写死颜色
- 浅色和深色模式使用同一套结构，只切换 token
- 强调色尽量保持统一品牌感
- 所有组件都必须从一开始兼容深色模式

### 建议主题变量

建议至少定义这些变量：

- `--bg`
- `--bg-soft`
- `--bg-elevated`
- `--text`
- `--text-muted`
- `--text-faint`
- `--border`
- `--border-strong`
- `--accent`
- `--accent-contrast`
- `--accent-soft`
- `--code-bg`

## 5. 配色建议

### 浅色模式

建议方向：
- 背景：偏暖白、米白、淡灰白
- 正文：深墨灰，不要纯黑
- 次级文字：中灰偏暖
- 边框：低存在感浅灰
- 强调色：选择一个稳定、耐看的色系

可选强调色方向：
- 深青绿
- 低饱和蓝
- 铜橙
- 暗红棕

### 深色模式

建议方向：
- 背景：深墨蓝灰、深炭灰，不用纯黑
- 正文：柔和浅灰白
- 次级文字：灰蓝或灰棕中间值
- 表层容器：比背景轻微抬起
- 强调色：保持同一色相，提升亮度与可见度

### 配色原则

- 不追求“颜色多”，只需要 1 个主强调色
- 状态色要节制使用
- 标签色不要每个标签一个鲜艳颜色，会破坏整体统一感
- 文章区域颜色变化要少，避免干扰阅读

## 6. 字体与排版

### 字体策略

建议区分：
- 中文正文
- 英文标题 / UI 辅助文字

可采用的思路：
- 中文正文：系统中文字体或更稳重的阅读型字体
- 英文标题：更有识别度的标题字体，但不能太花
- 代码字体：固定宽度字体，强调清晰度

### 排版原则

- 标题层级清晰
- 正文行高充足
- 段落间距统一
- 正文宽度控制在舒适阅读范围
- 首页和文章页的排版节奏要明显不同

### 建议阅读宽度

- 文章正文容器宽度保持克制
- 不要让正文铺太满
- 代码块可略宽，但需要移动端滚动友好

## 7. 布局规范

### 全局布局

建议采用：
- 顶部导航
- 主内容区
- 页脚

全站横向宽度建议设置统一容器：
- 首页可稍宽
- 文章页可稍窄
- 列表页居中并控制节奏

### 间距系统

建议统一用一套节奏，不要随手写：
- 超小间距：图标、标签内部
- 小间距：按钮和辅助信息
- 中间距：卡片内部、模块内部
- 大间距：页面区块之间
- 超大间距：首页首屏和重要段落之间

## 8. 组件风格规范

### 导航栏

要求：
- 简洁
- 清晰
- 不要过高
- 要包含主题切换按钮

风格建议：
- 半透明或轻微磨砂可选，但不要太重
- 滚动后可以有轻微背景提升

### 按钮

建议只保留少量按钮层级：
- 主按钮
- 次按钮
- 文字按钮

要求：
- 圆角不要过大
- 不要使用过强渐变
- hover 状态轻量即可

### 卡片

列表卡片建议：
- 更像信息容器，不是营销组件
- 边框、背景和阴影都要轻
- 标题信息优先，装饰性次之

### 标签

标签需要：
- 清晰但不抢眼
- 在明暗模式下都可辨识
- 保持统一样式，不做五颜六色

### 页脚

页脚建议包含：
- 简短版权信息
- 一句简短说明
- 社交链接

风格上要尽量轻，不要抢主内容注意力

## 9. 首页设计规范

首页应该是最有个人感的页面。

### 首屏内容建议

- 你的名字或站点名
- 一句清晰的身份描述
- 一小段介绍
- 主要行动入口，例如“阅读文章”“了解我”

### 首页模块节奏

建议从上到下形成清晰层级：

1. 首屏建立印象
2. 最近写了什么
3. 我关注哪些主题
4. 我是谁 / 我在做什么

### 首页不要堆太多东西

不建议第一版首页出现：
- 太多分类入口
- 太多文章卡片
- 太多社交模块
- 太长的自述

## 10. 文章页设计规范

文章页是整个博客最重要的页面。

### 文章头部

建议包含：
- 标题
- 描述
- 发布时间
- 更新时间
- 标签
- 阅读时长

### 正文体验

要求：
- 段落、标题、列表、引用、代码都要有统一规则
- 一级和二级标题视觉层级要明显
- 链接样式既要显眼又不能太跳
- 引用块要有清晰但克制的视觉提示

### 代码块

代码块需要重点处理：
- 浅色和深色分别优化
- 保持足够对比度
- 支持横向滚动
- 代码区域和正文背景要明显区分

### 附加导航

建议支持：
- 返回博客列表
- 上一篇 / 下一篇
- 标签跳转

## 11. 博客列表页规范

列表页应优先突出信息结构，而不是装饰。

每篇文章建议展示：
- 标题
- 日期
- 简短摘要
- 标签

视觉上建议：
- 行式列表或轻卡片列表
- 保持节奏整齐
- 不要让封面图压过标题信息

## 12. 深色模式详细规范

### 深色模式目标

- 不是“能用就行”，而是完整体验的一部分
- 保持博客整体气质不变
- 保证长时间阅读舒适

### 深色模式需要重点检查的区域

- 正文文字颜色
- 链接颜色
- 代码块背景
- 边框存在感
- 页头 / 页脚层次
- 标签对比度
- 封面图和插图是否突兀

### 切换体验

- 切换时避免闪烁
- 初始加载要尽量减少主题错误闪现
- 切换动画短而克制

## 13. 动效规范

整体动效策略：
- 少而准
- 以页面进入、模块淡入、按钮反馈为主

建议保留的动效：
- 页面进入轻微淡入
- 首页部分模块轻微上移出现
- 按钮 hover 微弱反馈
- 主题切换轻量过渡

不建议：
- 大范围位移
- 复杂视差
- 连续自动播放动画

## 14. 响应式规范

### 移动端优先注意点

- 导航不要拥挤
- 首页首屏不要过高
- 标题不要太长造成压缩
- 文章页代码块要支持横向滚动
- 标签和按钮点击区域足够大

### 平板和桌面端

- 桌面端要体现呼吸感
- 不要因为屏幕大就把内容拉得很散
- 阅读宽度控制优先于“占满空间”

## 15. 设计落地建议

在真正开始写界面前，建议先固定以下内容：

- 品牌主色
- 浅色模式主背景和正文色
- 深色模式主背景和正文色
- 标题字体策略
- 正文字体策略
- 按钮和卡片圆角规则
- 页面容器宽度

这些一旦先定下来，后面搭页面会稳定很多。

## 16. 当前结论

这套博客的设计应该走：

“强排版、弱装饰、重阅读、有人味、完整深色模式”

的方向。

第一版不追求炫技，而是先把以下事情做漂亮：
- 首页第一印象
- 文章阅读体验
- 深色模式一致性
- 组件风格统一
- 响应式稳定
